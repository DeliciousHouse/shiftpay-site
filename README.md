# shiftpay-site

Public support, privacy policy, and pay-calculation pages for the ShiftPay app, published with GitHub Pages at https://delicioushouse.github.io/shiftpay-site/.

The site is plain static HTML with no build step, scripts, analytics, or external assets:

- `index.html` — home page linking to the pages below
- `support/index.html` — support and troubleshooting
- `privacy/index.html` — privacy policy
- `pay-calculations/index.html` — how ShiftPay calculates pay
- `.nojekyll` — serves the files as-is, without Jekyll processing
